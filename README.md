## ✨ Features

* **Modern dark theme** with teal/purple gradient branding and glassmorphism navbar
* **Fully responsive** — desktop, tablet and mobile with an animated hamburger menu
* **Animated hero** with a rotating role typing effect and profile card
* **Scroll experience** — scroll-reveal animations, scroll-progress bar and back-to-top button
* **Active nav highlighting** based on the section in view
* **WhatsApp integration** — clickable chat links and a floating WhatsApp button
* **Downloadable resume** bundled inside the project

---

## 🛠 Tech Stack

* HTML5
* CSS3 (custom properties, Grid, Flexbox, media queries — no framework)
* Vanilla JavaScript (IntersectionObserver, typing effect)
* Font Awesome 6 (icons)
* Google Fonts (Poppins)

## 💻 Getting Started

1. **Clone the repo**

   ```
   git clone https://github.com/Nadeem-mohammad0021/Portfolio.git
   cd Portfolio
   ```

2. **Open it** — no build step or dependencies required. Either open `index.html` directly, or run a local server:

   ```
   python -m http.server 5500
   ```

   Then visit `http://localhost:5500`.

---

## 📦 Deployment

Use **GitHub Pages**:

1. Push the project to a repository.
2. Repo **Settings → Pages** → select the `main` branch and `/ (root)` source.
3. Save — the site goes live at `https://<your-username>.github.io/Portfolio`.
